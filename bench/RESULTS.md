# 基准结果

度量：插入的 **buffer + splitter 总数（B+S）**。AQFP 里两者都是"一个占一级相位的单元"，mockturtle 的文档也把它们当作同一种元件来计数。
所有新版结果都经过三重检查：独立校验器（单负载 / 相位一致 / 输出对齐）、功能等价（≤14 输入穷举，否则 2048 组随机）、
流水线相位仿真（连续 32 个周期每周期一组新输入，0 错 0 X）。

共同假设：主输入在第 0 相位到达且需要 splitter；所有主输出对齐到同一相位；splitter 最多 4 路；输出相位取**最小可行深度**。

- 原版 13 个里只有 parity32（纯 XOR 树、没有重汇聚）是对的；它的 B+S 有时比新版少，是因为它**少插了必须插的单元**，不能拿来比。

## 2. 与 mockturtle 对比（同一个 AIG）

[mockturtle](https://github.com/lsils/mockturtle)（EPFL LSI，commit 47d1e70，2026-09-29）是 AQFP buffer 插入的主流开源实现，
对应论文 *Depth-optimal Buffer and Splitter Insertion and Optimization in AQFP Circuits*（ASP-DAC 2023）。
为保证可比，先让 mockturtle 读入并结构哈希，再把**它实际用的 AIG** 读回 v2v2j，两边跑同一个网表。
mockturtle 设置：`balance_cios=true, ci_capacity=1, splitter_capacity=4, num_phases=1`；它的 depth 含主输入寄存器的 4 相偏移，表中已减去。
复现：编译 `bench/mt_bench.cpp` 后 `MT_BENCH=./mt_bench python bench/mockturtle_compare.py`

读法与限度（请按证据强度区分）：
- **较强**：两边在同一网表、同一假设下，深度全部相同（都是最小深度），v2v2j 的 B+S 在 7 个电路上与 mockturtle 最强的启发式持平、6 个上更少，
  双方结果各自通过了自己的校验器。
- **注意**：alu4 的 AIG 有 4 个输出取反无法用德摩根吸收，v2v2j 为此多放了 4 个 inv（算逻辑门，不计入 B+S），
  mockturtle 默认把输出端取反视为免费（`ignore_co_negation`）。这一项对 v2v2j 不利，结论不受影响。
- **没比的**：mockturtle 的 `optimal`（SMT 求全局最优）没有编进来；后续论文（如 DAC'22 *Beyond local optimality…*）的方法也没比。
  所以只能说"不输于 mockturtle 的启发式"，不能说"达到最优"。
- **规模**：这些都是几十到几百门的小电路；EPFL 基准那种上万门的电路没测，Python 实现的运行时间会是瓶颈（mul8 约 0.5 s）。

## 3. 电路级验证（JoSIM）

`tests/test_josim.py`：用 JoSIM 仓库自带的 HSTP π-DQFP buffer/inverter 子电路，把 `y = ~a` 插成 2–9 级的流水线，
每个时钟周期（5 GHz）换一组输入，10 个周期的输出全部正确；故意把两个相邻 buffer 的相位对调，输出立刻出错（负对照）。
这验证的是**励磁接线、相位方案、采样时刻**，不验证逻辑门的电路（演示库里没有 AND/OR/splitter 的子电路）。

一个意外的观察（只在这一个电路、无噪声的理想仿真里看到，属于初步现象）：把某个 buffer 改到与相邻级**同相位**时，JoSIM 里输出仍然正确——
同相位的两级像一根导线一样直接传递；而改成"晚 2 相或倒退"时会错位或卡死。`v2v2j.sim.phase_sim` 对前一种情况判 X，是偏保守的教学模型。
