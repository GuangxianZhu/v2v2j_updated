AQFP 相位实验台

绝热量子磁通参量器（AQFP）的每个门都由交流励磁按相位驱动，信号一级一级往前"接力"。 插 buffer 和 splitter，就是让每一棒都恰好落在下一相位上。下面用同一组电路对比原版算法和新版算法，你可以一步步看，也可以通电跑起来。

约束一：每个输出只能驱动一个负载

AQFP 门的输出电流只有几十微安，分给两个负载就判不清 0/1。要驱动多个负载，必须先过 splitter（1 进 2~4 出），而 splitter 自己也占一个相位。

约束二：所有输入必须来自上一相位

第 L 级的门只在相位 (L−1) mod 4 被激励，它读的是上一相位刚算好、仍在保持的输出。路径短了就得补 buffer，否则读到的不是没励磁的空值，就是别的周期的数据。

输出对齐

所有主输出在同一相位取出，电路才能每个时钟周期吃一组新输入（整体就是一条门级流水线）。

算法

每个时钟周期送入一组随机输入（主输入在第 0 级），读数表在每个输出的采样时刻填一行。黑色实线 = 1，浅色 = 0，橙色虚线 = X（源头此刻没有励磁或同时在翻转）。

    一根线上的树怎么搭最省

    驱动在第 L₀ 级，负载 i 要求在第 rᵢ 级拿到拷贝。从最深的负载往回推：

    c(t) = s(t) + ⌈c(t+1) / k⌉ 可行 ⇔ c(L₀) ≤ 1 单元数 = Σ ⌈c(t) / k⌉

    s(t) 是第 t 级直接取走的拷贝数，k 是 splitter 最大扇出。每一级都取到了下界，所以对固定的负载相位它就是最少单元数测试里与穷举对照。 原版"先分裂、再各自补 buffer"会让很多层的 c(t) 大于 1，这就是全加器里多出 4 个 buffer 的来源。

    扇出 n 要推迟几级

    保守做法是所有负载统一推迟 ⌈log_k n⌉ 级。精确条件是 Kraft 不等式：

    Σ k^−(rᵢ − L₀) ≤ 1

    比如扇出 5、k=4：3 个负载隔 1 级、2 个隔 2 级就够了（3/4 + 2/16 ≤ 1）。新版先用保守约束做线性规划，再用精确判据压缩深度、局部搜索13 个电路上深度与 mockturtle 一致。

    为什么线性规划给出整数解

    把"buffer 数"近似成每根线上最长 buffer 链的长度，所有约束都是 xᵢ − xⱼ ≤ c 的差分形式。这类约束矩阵是全幺模的，单纯形法给出的顶点解天然是整数。 近似在扇出大于 1 时是下界，所以最后仍用精确的树代价挑最优合计比 ASAP 少约 27%。

    这个仿真器有多可信

    页面里的"通电运行"是离散的相位模型：读的源头必须恰好早一个相位，否则判 X。JoSIM 电路级仿真里，同相位相邻的两级有时也能正确传递，所以它偏保守只在一个电路上观察到。 真正的结论以 JoSIM 和你自己的单元库为准。
